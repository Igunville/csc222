# Stack Versus Heap
### Stack
- Automatically Allocated by the CPU
- Very fast but size is limited
- data must have a fixed size
- It's lifetime is tied to the function that created it

### Heap
- It is requested manually by code
- It has no reasonable size limit
- It can have a flexuble lifespan until it is deleted

# Uses of Each
### Stack
- The stack is used for function calls, temporary data and local varibales

### Heap
- The Heap is used for data or memory that is allocated and can have a lifetime
longer than a single function
